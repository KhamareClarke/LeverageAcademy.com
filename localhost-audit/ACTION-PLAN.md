## 🔴 PHASE 1 — Day 1 | Unblock the Site (3 fixes, ~2 hours)

These three issues prevent ALL organic search visibility. Nothing else matters until these are done.

### 1. Fix HTTP 500 — Add Supabase environment variables
**Impact:** Fixes complete site outage for all crawlers and visitors  
Create `.env.local` in project root:
```
NEXT_PUBLIC_SUPABASE_URL=<your-supabase-url>
NEXT_PUBLIC_SUPABASE_ANON_KEY=<your-supabase-anon-key>
```
Also add to your production hosting environment (Vercel, etc.).

### 2. Narrow middleware to protected routes only
**Impact:** Decouples homepage from Supabase — public pages work even if Supabase is down  
**File:** `middleware.ts`
```ts
export const config = {
  matcher: ['/student/:path*', '/admin/:path*', '/apply/:path*'],
}
```

### 3. Remove `'use client'` from homepage
**Impact:** All marketing content becomes visible to Googlebot  
**File:** `app/page.tsx` — remove `'use client'` from line 1. The Framer Motion components can remain as Client Components within their own files.

## 🟠 PHASE 2 — Week 1 | Discoverability Foundation (~4 hours)

### 4. Add robots.txt
**File:** `app/robots.ts` (new file)
```ts
import { MetadataRoute } from 'next'
export default function robots(): MetadataRoute.Robots {
  return {
    rules: [{ userAgent: '*', allow: '/', disallow: ['/admin/', '/api/'] }],
    sitemap: 'https://leverageacademy.com/sitemap.xml',
  }
}
```
